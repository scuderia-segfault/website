Here is what goes into Unit XIII.

| Part | What we use |
| --- | --- |
| Chassis | Serpent SRX8GTE R (1:8, four-wheel drive) |
| Motor | Hobbywing Xerun 4268SD G3, 2400 KV |
| Motor controller | VESC 6 MkVI HP |
| Steering servo | Doyono DHS60 |
| LiDAR | RoboSense Airy |
| IMU | MicroStrain 3DM-GX5-25 |
| Optical flow | Holybro H-Flow |
| Computer | ASUS NUC 15 Pro or NVIDIA Jetson |

The LiDAR sits on top with a clear view all around. The IMU gets a rigid mount, and the optical flow sensor points down at the floor.

We haven't picked the computer yet. If we add a ZED X Mini camera, we need a Jetson, because the camera connects over GMSL2.
